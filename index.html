🧠 MicroML.js

Minimal Machine Learning Framework for the Web

📋 Core Philosophy

Everything is built from just 3 operation types:

  • UnaryOps - Single tensor operations (relu, exp, log, etc.)
  • BinaryOps - Two tensor operations (add, mul, etc.)
  • ReduceOps - Reduction operations (sum, max, etc.)

🎯 "If XLA is CISC, MicroML is RISC" - Radical simplicity over feature bloat

🚀 Basic Tensor Operations

const a = new Tensor([[1, 2], [3, 4]]); const b = new Tensor([[5, 6], [7, 8]]); const result = a.add(b).mul(new Tensor([[2, 2], [2, 2]])); console.log(result.realize()); // Lazy execution until .realize()

🔗 Lazy Operation Chain Visualization

// Operations are lazy - they build a computation graph const x = new Tensor([[1, 2, 3]]); const chain = x.mul(2).add(1).sum().exp(); console.log('Operation chain:', chain.getOpChain());

🧮 Neural Network Example

// Simple linear layer: y = xW + b function linear(x, weight, bias) { return x.matmul(weight).add(bias); } // ReLU activation (UnaryOp) function relu(x) { return x.relu(); } // Simple 2-layer network const input = new Tensor([[0.5, -0.2, 0.1]]); const w1 = new Tensor([[0.1, 0.2], [-0.1, 0.3], [0.2, -0.1]]); const b1 = new Tensor([[0.1, -0.05]]); const w2 = new Tensor([[0.5], [-0.3]]); const b2 = new Tensor([[0.1]]); const output = linear(relu(linear(input, w1, b1)), w2, b2);
